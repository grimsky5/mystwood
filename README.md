# What is this?

Mystwood is a mod for Not So Seecret Saturday (NSSS) a1.1.12.

## How to install

Simply paste all contents of the provided ZIP inside a vanilla NSSS 1.1.12 JAR.

* If you do not have NSSS, get it here:

https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/2916817-the-not-so-seecret-saturday-mod-for-alpha-1-1-2_01

* If you have other mods downloaded on NSSS, I can't guarantee compatibility. This mod modifies many classes, and I haven't tested it with other mods. Very few mods exist for NSSS, so this shouldn't be much of an issue.

* If your launcher requires a JSON, use the one provided.

* If you have questions, contact Classic Minecraftian on his YouTube channel.

* For feedback, suggestions and bug reports, you may comment those on Classic Minecraftian's channel. Please provide enough information for a bug report and how to replicate the bug.

* If you want to upload about this mod on your channel, please credit the creator, Classic Minecraftian, and provide this same archive for the download.

* Beware that this will have bugs, as my playtesting didn't cover every possible outcome and scenario, so please do report any bug you encounter. I plan on continuing this mod's development, v1.1 is pretty much a possibility I have in my head.
